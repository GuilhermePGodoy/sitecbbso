Por que trocar para React

Antes: HTML duplicado, elenco fixo no código, zero reuso.

React + Vite:

  • Reuso: componentes (PlayerCard, Banner, Menu…)
  • Dados dinâmicos: estado + API → tela sempre reflete o banco
  • react-router: várias páginas numa SPA, sem recarregar
  • Vite: dev rápido + build otimizado
  • Stack ensinado na disciplina

Bootstrap 5 usado de forma seletiva — identidade visual própria preservada (amarelo, Manrope).

Autenticação & segurança

  • Senha guardada com bcryptjs (hash) — nunca em texto puro
  • Login confere a senha → gera um JWT assinado
  • Token vai num cookie httpOnly (7 dias) — o JS não acessa
  • Middleware auth valida o token em toda rota de escrita
// token carrega a identidade assinada → { sub, nome, email, admin }
